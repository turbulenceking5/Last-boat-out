# Last Boat to Calder: documentation

Two games about the same outbreak:

- **[Last Boat to Calder](https://turbulenceking5.github.io/Last-boat-out/)**: the turn-based original. Command Vessmark's army across 21 places for two weeks.
- **[Last Boat to Calder: City](https://turbulenceking5.github.io/Last-boat-out/city/)**: a real-time 3D take. Fight for one city street by street for 12 minutes.
